## Контекст: ресерч (03.08.2026)

**Факторы Яндекса** (веб-ресерч): коммерческие факторы — топ-3 сигнал по
коммерческим запросам (видимые цены, контакты, способы заказа); региональность —
топ-3 по гео-запросам (регион в Вебмастере + город в title/текстах); поведенческие
~65% (сниппеты: title/description/крошки); семантика автосервиса = «услуга × марка
× город», статьи вторичны, но инфо-кластер конвертит; быстрая индексация =
Вебмастер + Метрика (обход по счётчикам) + IndexNow; Schema.org валидируется
Вебмастером (AutoRepair, BreadcrumbList, FAQPage, Product/Offer).

**Семантическое ядро** (Букварикс «Весь мир»/мес + подсказки Яндекса):
- **Аренда ~7 000** — «аренда гелика» 3 019 (+москва 733/640, в москве 566, без
  водителя 331, на сутки 203, с водителем 141), «аренда гелендвагена» 2 517
  (+москва 923/893, в москве 766, без водителя 449, на сутки 182, на свадьбу 68).
  САМЫЙ ЖИРНЫЙ кластер, в 10 раз больше ремонта.
- **Ремонт/сервис ~800** — «ремонт гелендваген(а)» 270 (+москва 33), «ремонт
  гелика» ~300, «сервис гелендваген» ~125 (+«клубный сервис» 20), «обслуживание»
  ~180 (+«сколько стоит обслуживание» ~50), узлы: рулевой редуктор 9, раздатка 9,
  передний мост 8, кузовной 17, задний редуктор (подсказки).
- **Запчасти ~600** — «запчасти (на) гелендваген» ~370, «купить на запчасти» 26×3,
  w463 5.
- **Инфо-потенциал** — «гелендваген» 124k, «мерседес гелендваген» 17.6k, «купить»
  14k, «цена» 8.2k, «дорог ли в обслуживании» — темы статей.
- Выводы: обе формы «гелик»/«гелендваген» обязательны; латиница «g class ремонт»
  мизер (54); опечатки («гелентваген») Яндекс нормализует сам — не таргетируем.

**Аудит кода** (агент, 03.08): pageSeo в lib/seo.ts — рабочий каркас, но вложенный
openGraph ЗАТИРАЕТ корневой → og:image нет ни на одной индексируемой странице
(docs Next 16: nested fields overwritten). Заявленный размер OG 1200×630 ≠ файл
1920×1080. verification-полей нет; Setting-реестр (lib/settings.ts KNOWN_SETTINGS)
позволяет добавить ключ без миграции. sitemap.ts запекается статически при сборке
без БД → в проде 9 URL без услуг/моделей/запчастей. Модель Service: slug, name,
description (строка), priceMin/Max, durationMinutes — цены НА страницах есть,
SEO-полей/FAQ/длинного текста нет. JSON-LD только AutoRepair в (public)/layout
(без addressLocality/geo, openingHours не в формате schema). Крошки — 4 инлайн
копии без разметки. BlogPost в схеме есть, использований ноль. /models нет в
десктоп-навигации. /profile, /booking/step-2,3 без NOINDEX (наследуют canonical
«/»). Метрики Яндекса в коде нет. force-dynamic везде, revalidate нигде.

## Implementation Tasks

### Story 1: Технический фундамент индексации
**Objective:** починить всё, что мешает Яндексу видеть сайт целиком, и дать
владельцу рычаги (верификация, Метрика, IndexNow) без деплоя на каждое значение.
**Tasks:**
1. `app/sitemap.ts` → `export const dynamic = "force-dynamic"` (в проде sitemap
   отдаёт услуги/модели/запчасти/аренду из БД, а не билд-заглушку).
2. Гигиена индекса: NOINDEX для `/booking/step-2`, `/booking/step-3`, `/profile`
   (+ им же собственный canonical или отсутствие oг-наследия «/»); `/profile` в
   robots disallow; убрать несуществующий `/master` из robots.
3. `lib/seo.ts` pageSeo: дефолтная OG-картинка (hero) когда `image` не передан —
   баг перезатирания вложенного openGraph; в `app/layout.tsx` исправить размер
   1920×1080.
4. Верификация: ключи `YANDEX_VERIFICATION` и `GOOGLE_SITE_VERIFICATION` в
   `KNOWN_SETTINGS` (group SEO) + вывод `<meta name="yandex-verification">` в
   корневом layout когда заданы.
5. Яндекс.Метрика: ключ `YANDEX_METRIKA_ID` в Settings + компонент со скриптом
   (только публичный layout, только когда ID задан).
6. IndexNow: ключ `INDEXNOW_KEY` в Settings, роут `app/[key]/route.ts`-стиля
   (отдаёт key.txt по протоколу), `lib/indexnow.ts` ping-хелпер (fire-and-forget)
   в server actions услуг/запчастей/аренды/моделей.
**DoD:** tsc/lint/vitest/build зелёные; юнит-тесты на pageSeo (og:image default),
IndexNow route (200 при совпадении ключа, 404 иначе); curl прод-проверки после
деплоя: sitemap >9 URL, meta verification присутствует при заданном Setting.

### Story 2: Микроразметка Schema.org
**Objective:** дать Яндексу структурированные данные для сниппетов и валидатора
Вебмастера.
**Tasks:**
1. `buildOrganizationJsonLd` → добавить `addressLocality: "Москва"`,
   `addressCountry`, `priceRange`, `openingHoursSpecification` (парсер CMS-строки
   «Пн–Пт: 10:00–20:00…» → Mo-Fr 10:00-20:00, с юнит-тестом), `sameAs` из
   fab.channels (Telegram/MAX/WhatsApp URL).
2. Компонент `Breadcrumbs` (визуал + BreadcrumbList JSON-LD), заменить 4 инлайн
   копии: services/[slug], models/[slug], parts/[slug], rentals/[id].
3. `/services/[slug]`: JSON-LD `Service` + `Offer` (priceMin, RUB, provider @id
   организации).
4. `/parts/[slug]`: `Product` + `Offer` (цена, наличие).
5. Главная: `FAQPage` из CMS FAQ (6 вопросов).
**DoD:** каждый JSON-LD собирается чистой функцией в `lib/seo-jsonld.ts` с
юнит-тестами (валидный JSON, обязательные поля, эскейп `<`); полный гейт.

**Tasks:**

**DoD:** тесты на билдеры заголовков; грепы «Москва» на листингах в SSR-выдаче

### Story 4: Контент страниц услуг (схема+админка+черновики)
**Objective:** страницы услуг перестают быть ~50 слов — структура под 300–600
слов: этапы, FAQ, длинный текст; правится из админки.
**Tasks:**
1. Миграция: Service + `body String? @db.Text` (markdown), `faq Json?`
   (массив {q,a}) — аддитивно.
2. ServiceForm админки: textarea body (markdown), редактор FAQ (пары вопрос/ответ).
3. `/services/[slug]`: рендер body (тот же markdown-рендерер, что у CMS
   richtext), FAQ-аккордеон + FAQPage JSON-LD (расширение Story 2).
4. Черновики контента: data-миграция заполняет body/faq для 10 услуг ТОЛЬКО где
   body IS NULL (идемпотентно) — тексты по узлам G-Class (редуктор, раздатка,
   мост — из ядра), с маркером «проверьте цены» для владельца в ледджере, БЕЗ
   выдуманных фактов о компании.
**DoD:** тесты экшена сохранения; SSR-страница услуги рендерит body и FAQ; объём
текста страницы «АКПП» ≥300 слов в dev; полный гейт; migrate deploy применит

**Tasks:**
1. `/rentals` metadata: title «Аренда Гелендвагена (Гелика) в Москве — G-Class с
