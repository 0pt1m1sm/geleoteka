# Прайс из файла: массовое заведение товаров

Created: 2026-09-01
Status: PENDING
Type: Feature
PRD: docs/prd/2026-09-01-bazon-gaps.md (Story A)

## Зачем

Существующий импорт (`app/api/parts/import/route.ts`) заводит **справочник** — `PartReference`:
имя, OEM, совместимость. Ни цены, ни остатка, ни склада. Продавать по нему нельзя: товар
(`Part`) с ценой и `StockItem` с количеством по-прежнему заводятся руками, по одному. Прайс
поставщика на триста строк так не заносят.

## Решения, принятые до начала

**Никакой библиотеки для XLSX.** Excel кладёт в буфер обмена TSV — вставка таблицы покрывает
тот же сценарий без зависимости (у SheetJS длинная история уязвимостей, а прошлый разбор
зависимостей мы закрывали в ноль). Формы две: вставка таблицы и загрузка CSV. Файл `.xlsx`
форма отклоняет с внятной подсказкой «сохраните как CSV или вставьте таблицу».

**Импорт идемпотентен.** Ключ строки — SKU (для новых он равен OEM). Повторная загрузка того
же файла обновляет цену и остаток, а не создаёт вторую строку. Иначе первый же
перезалитый прайс удвоит каталог.

**Остаток задаётся, а не прибавляется.** Файл — это снимок прайса, а не приход. Изменение
остатка проводится движением через существующий механизм, чтобы журнал остался связным.

## Формат

| Столбец | Обяз. | Смысл |
|---|---|---|
| `oem` | да | номер; при отсутствии в справочнике позиция создаётся |
| `name` | для новых | название; для существующих берётся из справочника |
| `price` | да | цена в рублях, целое |
| `qty` | нет | остаток; пусто — не трогать |
| `warehouse` | нет | код склада; пусто — склад по умолчанию |
| `condition` | нет | `новый` / `бу` / `восстановленный`; пусто — новый |
| `conditionNote` | нет | дефекты (только для б/у) |
| `originNote` | нет | с какой машины снято (только для б/у) |

### Story 1: Разбор и предпросмотр

**Цель.** Чистая функция, превращающая текст прайса в план изменений, без обращения к базе на
уровне разбора и с проверкой на уровне сверки.

**Файлы.** `lib/parts/price-import.ts` (новый), `tests/parts/price-import.test.ts` (новый).

**Готово, когда:**
- разделитель определяется сам (табуляция или запятая), заголовок распознаётся по именам
  столбцов в любом порядке и на русском тоже («номер», «цена», «кол-во»);
- цена принимает `18 500`, `18500,00`, `18 500 ₽` и отвергает `-1`, `0`, буквы;
- каждая строка получает исход: `создать` / `обновить` / `отклонить` с причиной;
- б/у-строка без `conditionNote` отклоняется — экземпляр без описания состояния продавать
  нельзя (правило уже действует в `lib/parts/used-part-validation.ts`, переиспользовать его);
- дубли OEM внутри одного файла отклоняются оба, а не «выигрывает последний»;
- каждый тест закрыт мутантом.

### Story 2: Запись

**Цель.** Применить план одной транзакцией.

**Файлы.** `app/actions/parts-price-import.ts` (новый), `lib/part-sku.ts` (переиспользовать
`newPartSku`, `duplicateNewPartWhere`), `tests/parts/price-import-apply.test.ts` (новый).

**Готово, когда:**
- `requireRole(["ADMIN","MANAGER"])`, запись только из плана, посчитанного на сервере: клиент
  присылает исходный текст, а не готовые строки (иначе цену можно подделать);
- отсутствующая номенклатура создаётся через `ensurePartReference` — тот же путь, что у
  импорта справочника, с `oemKey`/`isLatinOem`;
- остаток выставляется движением, журнал движений остаётся связным;
- отклонённые строки не мешают принятым: файл применяется частично, отчёт показывает обе части;
- запись целиком в транзакции: падение на двухсотой строке не оставляет полкаталога;
- `recordAudit` на применение с числом созданных и обновлённых.

### Story 3: Экран

**Цель.** Менеджер видит, что произойдёт, до того, как это произойдёт.

**Файлы.** `components/admin/PartsPriceImportForm.tsx` (новый),
`app/(admin)/admin/parts/page.tsx` (кнопка).

**Готово, когда:**
- две вкладки — вставка таблицы и файл; `.xlsx` отклоняется подсказкой;
- предпросмотр таблицей: строка, исход, причина отклонения;
- кнопка применения недоступна, пока в плане нет ни одной принятой строки;
- после применения — отчёт и ссылка на список товаров с фильтром по последнему импорту.

## Риски

**Ошибка в цене уходит в витрину и в фид Avito.** Смягчение: предпросмотр обязателен, цена
показывается отформатированной (`formatPrice`) — `1 850 000 ₽` вместо `18 500` видно глазом.
Этот же промах уже случался при заведении демо-товара.

## Проверка

Гейт: `npx tsc --noEmit`, `npm test`, `npm run lint`, `npm run build`. Плюс живая проверка на
локальном сервере: файл из тридцати строк, повторная загрузка того же файла (каталог не
удвоился), файл с битой строкой (принята часть).
